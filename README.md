# FPTU Auto Orches Click

Welcome to the **FPTU Auto Orches Click** project! This project aims to automate various tasks at FPTU (FPT University).

## Features
- **User-friendly Interface:** Easy navigation and usability.
- **Automation Tasks:** Tasks are automated efficiently.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/MaxxAlan/FPTU-Auto-Orches-click.git
   ```
2. Install dependencies:
   ```bash
   cd FPTU-Auto-Orches-click
   npm install
   ```

## Usage
After installation, run the application using:
```bash
npm start
```
